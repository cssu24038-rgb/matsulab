# ドメイン検知 — 画面遷移プロトタイプ

送信ドメインの信頼性評価アプリの **画面遷移だけ** を実装したプロトタイプです。
ドメイン判定・メール保存・削除はすべてダミーで動きます。

## 起動方法

```bash
cd /Users/home/Desktop/ドメイン検知
.venv/bin/python app.py
```

ブラウザで <http://127.0.0.1:5050> を開いてください。
ログイン画面の「Google でログイン」はデモ用で、実際の OAuth 認証は行いません。

## 画面一覧

| 画面 | URL | 内容 |
|---|---|---|
| ログイン | `/login` | Google ログイン（デモ） |
| ホーム | `/` | ドメイン入力、最近の調査、保存メール、危険度の凡例 |
| 判定結果（やさしい表示） | `/result/<id>` | 5段階の危険度、ひと目でわかる判定、やさしい根拠、メール保存 |
| くわしい表示 | `/result/<id>/detail` | SPF / DKIM / DMARC、VirusTotal、WHOIS などの技術的根拠 |
| 保存したメール一覧 | `/mails` | 保存した危険メールの一覧・削除 |
| 保存メール詳細 | `/mails/<id>` | メール情報、本文（ダミー）、メモ、判定結果へのリンク |
| 調査履歴 | `/history` | これまでに調べたドメインの一覧 |

## 画面の流れ

```text
ログイン
  └→ ホーム（メールアドレス / ドメインを入力）
       └→ 判定結果（やさしい表示）
            ├→ くわしい表示（専門家向け） ⇄ やさしい表示
            ├→ このメールを保存 → 保存したメール一覧 → メール詳細 → 削除
            └→ もう一度調べる → ホーム
  └→ 保存したメール / 調査履歴（ヘッダーのナビ）
```

## ダミー実装と差し替えポイント

| 機能 | 現在の実装 | 後からやること |
|---|---|---|
| ドメイン判定 | `analyzer.py` がドメイン名から決定的に疑似結果を生成 | `analyze()` を VirusTotal / DNS ルックアップに置き換える |
| データ保存 | `store.py` のインメモリリスト（再起動でリセット） | SQLite などに置き換える。関数のインターフェースはそのまま使える |
| ログイン | セッションに固定ユーザーを入れるだけ | Google OAuth 2.0 / OpenID Connect |
| メール本文 | 固定のダミー文 | 実際に受信したメールを保存する |
| 削除 | リストから除くだけ | DB から削除 |

`app.py` のルーティングと `templates/` の画面は、そのまま本実装でも使える構成にしています。

## ファイル構成

```text
app.py              ルーティング / セッション / テンプレートフィルタ
analyzer.py         ダミーのドメイン判定ロジック（5段階）
store.py            判定結果・履歴・保存メールのインメモリ管理
templates/
  base.html         共通レイアウト（ヘッダー / フッター）
  login.html        ログイン
  index.html        ホーム
  result.html       判定結果（やさしい表示）
  detail.html       判定結果（くわしい表示）
  mails.html        保存メール一覧
  mail_detail.html  保存メール詳細
  history.html      調査履歴
  error.html        404
static/
  style.css         スタイル
  app.js            入力例チップ / 削除確認
```

## メモ

- 初回起動時に、危険度 1〜5 が一通り確認できるサンプル履歴を入れています。
- 入力例: `gmail.com`（安全）、`support-center.net`（注意）、`paypa1-secure.top`（非常に危険）など。
- 判定結果は同じドメインなら毎回同じになります（画面確認用）。
